# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Send an email to **jeffersonmk@proton.me** with:

- a description of the problem and its impact;
- steps to reproduce it;
- the Cashew Desktop version (shown in **About**).

You will get a reply as soon as possible. Once a fix is released, the
problem can be discussed publicly.

## Supported versions

Only the latest release receives fixes.
